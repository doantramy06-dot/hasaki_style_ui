# Hasaki-style UI (bài tập học tập)

- `index.html`: cấu trúc giao diện.
- `style.css`: màu sắc, bố cục và responsive.
- Mở thư mục bằng VS Code rồi chạy `index.html` bằng Live Server.

Lưu ý: Đây là giao diện mô phỏng lấy cảm hứng từ bố cục website thương mại điện tử Hasaki, không phải website chính thức. Tên, giá, khuyến mãi và ảnh sản phẩm chỉ mang tính minh họa. Tìm kiếm/lọc/sắp xếp chưa kết nối dữ liệu thật.
